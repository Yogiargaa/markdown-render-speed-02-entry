# markdown-render-speed-02 entry: faster drop-in for marked 18.1.3

A dependency-free Markdown parser producing HTML byte-for-byte identical to marked 18.1.3, measurably faster — an entry for the [markdown-render-speed-02](https://make.fun/bounty/markdown-render-speed-02) competition on [make.fun](https://make.fun). The driver renders each case on its own and writes the HTML array.

Run: `MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts`
